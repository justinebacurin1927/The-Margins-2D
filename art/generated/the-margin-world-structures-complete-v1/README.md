# The Margin — complete World Structures visual pass

This pass completes the eleven World-Structure visuals before their interaction systems are built.
The seven new atlases use the successful Hunter's Blind scale: 9×9 fog-aware cells, authored at
48 pixels per cell and reduced with nearest-neighbour filtering to 24-pixel runtime cells.
