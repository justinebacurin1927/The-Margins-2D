# The Margin Hunter's Blind v1

An authored 9×9-cell Tier-1 Hunter's Blind matching the game's multi-tile structures. The runtime
sheet is 216×216 pixels: exactly nine columns by nine rows of 24-pixel cells.

- `source/hunters-blind-chroma.png`: built-in image-generation result on flat magenta.
- `transparent/hunters-blind.png`: full-resolution transparency master.
- `runtime/hunters-blind-2x.png`: normalized 48-pixel authoring-grid version.
- `../../../assets/structures/hunters-blind.png`: nearest-neighbour runtime atlas.

The structure has a centered south ladder, an explorable raised deck, blocking support braces and
edge props, and a visible weak-plank area reserved for the later Tier-1 fall hazard.
