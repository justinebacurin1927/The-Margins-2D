- (version) Stack inherited from existing pom (NOT newly chosen): Java 17, libGDX 1.12.1, LWJGL3 backend, Maven multi-module. Newer libGDX (~1.13) exists but no reason to bump for MVP; ratify existing pin.
- (decision) AD-1 [ADOPTED] Package-by-feature under com.margins.rogue is the live home; legacy packages entity/ map/ screen(overworld)/ fx/ are FROZEN (not extended). New MVP code = new subpackages under rogue/. Prevents new work landing in dead legacy code.
- (decision) AD-2 Two layers: model (state+systems, no libGDX rendering deps) <- screen (input+render only). RogueGameScreen becomes I/O only; NO game rule may live in the Screen. Binds all FRs. Prevents the 303-line God-screen from absorbing 9 new systems; enables save + headless test.
- (decision) AD-3 One mutable RunState is the sole owner of all run data (tilemap, player, enemies, companion, inventory, flags, identify-map, seed, hunger, hp, lastStandUsed, current floor). Systems mutate it; nothing else holds authoritative duplicate. Binds all. Prevents two-owners divergence; RunState IS the save unit.
- (decision) AD-4 TurnEngine advances one turn by running ORDERED systems: PlayerAction -> Hunger -> Companion/Enemy AI (Detection update) -> Noise resolve -> cleanup/flags. New mechanics insert as an ordered system, never inline in the screen. Binds FR-3/4/5, hunger, combat. Prevents ad-hoc turn-ordering bugs.
- (decision) AD-5 Single seeded RNG owned by RunState, seeded per Run; ALL randomness (floor gen, identify-by-use binding, dodge) draws from it. Corrects current code's scattered new Random(). Binds FR-11, combat, floors. Prevents non-reproducible runs and save/reload desync.
- (decision) AD-6 Save = serialize whole RunState to ONE slot via libGDX Json; load = deserialize; delete-on-true-death. No seed+action-replay. Binds FR-20/21. Prevents replay brittleness when game logic changes.
- (decision) AD-7 Flags + Bond live in RunState as a run-scoped key/value store; DialogNode/QuestManager read/write ONLY through it. Binds FR-6/7/8, FR-15. Prevents narrative state scattering across objects; keeps it inside the save unit.
- (decision) AD-8 INSTINCT Check = DETERMINISTIC threshold compare (instinct >= node threshold), not a dice roll. Resolves addendum question. Rationale: authored beats stay reliable + save-stable, and matches fiction (Milek out-thinks, not out-lucks). Binds FR-7.
- (decision) AD-9 Detection = omnidirectional radius + line-of-sight (NOT directional vision cones) for MVP. Resolves PRD Q2. Enemy holds Detection enum; Noise = transient events in a RunState queue consumed on the AI system tick. Binds FR-3/4/5. Rationale: cones need facing+more tuning; radius is enough to prove stealth.
- (decision) AD-10 Companion (Galleon) is a RunState entity in its own list, implementing the same tile-actor/takeTurn contract as enemies but allied; runs in the turn pipeline; Distraction emits a Noise event (AD-9). Binds FR-13/14. Prevents companion being special-cased into the screen.
- (decision) AD-11 Story Floor = hand-authored FIXED layout loaded by FloorGenerator in a 'fixed' mode (not procedural). Resolves PRD Q4. Binds FR-18. Rationale: authorial control of the reunion beat > procedural variety for one floor.
- (direction) PRD Q1 (Galleon availability) is a DESIGN call, not architectural — AD-10 supports either. Recommend early recruitment so Distraction is taught before the reunion; left to Justine, logged for epics.
- (decision) AD-12 Identify-by-use: RunState holds SupplyType->TrueIdentity map built from the seed RNG at Run init + an 'identified' set. Ratifies existing Inventory type/count (stackable) model since identity is per-TYPE-per-seed. Binds FR-11/12, FR-9/10.
- (decision) Adversarial-gate fix: RunState is the sole serialization root; entities carry NO serialized back-refs to RunState-owned map/RNG (RoguePlayer currently holds both) - transient/injected + re-wired on load. Closes a save double-serialize/RNG-fork hole under AD-6.
