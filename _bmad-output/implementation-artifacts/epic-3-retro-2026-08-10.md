## What Went Well

1. **The deferral chains landed exactly as designed — the compounding engine, again.** The epic opened by closing deferred O4 (connectivity) in 3.1, then the deferred-work seams fed forward as a supply chain: 3.2's "Old House locked cellar has no spatial mapping" → **3.5's lockpicking**; "the 3.4 night-override seam doesn't exist yet" → **3.3 built the seam** → **3.4 authored the flips** → **3.5's KnowledgeSystem queried them**. The Epic 1 discipline (explicit out-of-scope seams + a traceable `deferred-work.md`) turned deferred items into full stories. Nothing was silently dropped.

2. **World-gen decided like a designer, not a coder.** 3.1's two decisions — the home-cluster anchoring (absolute constants vs fraction-resolved) and the Graveyard landing *exactly* on the `eastness 0.2f` cutoff — surfaced genuine design calls and were resolved to authored-tile behavior (the safe tier became `<= 0.2f`). 3.4's Beehive "drawless safer-flip" was accepted as correct-by-design (a safe location legitimately has no hazard event to roll), not patched. The seam (0.2f, day/night) kept surfacing real questions instead of hiding them.

3. **Save-migration rigor held across two more stories.** 3.2's review caught a **genuine load-path bug** the round-trip test missed — pre-3.2 saves restored structures + hazards but no authored loot; the persisted `structureLootPlaced` backfill flag fixed it (AD-6: default false → old saves backfill). 3.5 deliberately used FlagStore (no new `RunState` field) for the opened-cellar and map-fragment-knowledge state. The AD-6 rule (deterministic default OR load-time reconcile) was exercised, not recited.

4. **AD-5 seeded-stream discipline is now routine, not a scare.** Every "small fix" that would shift the rng stream got flagged, weighed, and either done AD-5-safely (the SKILL-clamp pin in 3.5) or deferred with explicit reasoning (supply retry-loop, count>1 stacking, eastness clamp). The byte-identical-scatter pin held across all five stories; the 3.1 refactor of `placeStructureLoot` → `placeLootInFootprint` was proven behavior-preserving by a pinned test.

5. **Precedent reuse paid off.** The Torn Page USE precedent became the MAP_FRAGMENT precedent (narration, no turn, never consumed) — reuse, not reinvention. The 3.2 `hazardsFireAcrossSeedsAndHonorAd5` determinism pattern was re-used as the 3.4 same-seed pin and the 3.5 lockpick determinism pin.

## Challenges / Friction

1. **Screen wiring lagged the core — this epic's sharpest miss.** Story 3.5 built LOCKPICK and the MAP_FRAGMENT read fully core-side with green tests, but **neither was reachable from the UI** — the review (blind + edge, two independent probes) caught it, and the Acceptance Auditor flagged the same as its one [Med] residual. Same class as Epic 1's silent-mutation finding, but for *input*: a feature exists and is tested, yet the player can't touch it. The patch (L key + MAP_FRAGMENT E-gate) was applied, but the process gap stands.

2. **Subagent-layer flakiness recurred.** 3.1's Blind Hunter failed 3× (1 API error, 2 timeouts) and was skipped; 3.2's Edge Case Hunter timed out once (retried ok); 3.5's Acceptance Auditor errored once (re-ran ok). The layer set is the quality gate; when one drops, coverage thins. Not a content problem — an infra/reliability one.

3. **Deferred-work grew to ~30+ entries** (18 open O-items + review defers). 3.2 alone deferred 10. Most are disciplined ("an AD-5-safe fix would shift the stream" / "no consumer yet"), but Epic 4's combat/economy will consume several (Rope/Small Tools → 4.5 repair; the equip slot → 4.4 gear). Needs a re-triage before/during Epic 4 so the backlog stays a working list, not an attic.

4. **Hazard diversity is thin.** All 11 hazards are one damage+message mechanic (3.2 deferred the spec's worked-example secondary effects — stumble / blocked tile); 3.4's night flips diversified only 4 locations. Combat (Epic 4) is the real test of whether variety matters.

5. **Decision-needed count was high early, tapered late.** 5 decisions in 3.1+3.2 (world-gen was genuinely ambiguous up front) vs 3 in 3.3–3.5. By the end, findings were mostly dismiss-with-reasoning — the seams had stabilized.

## Key Insights

- **Core-first + review-catches-UI is a real tax.** The "headless model, render-only screen" rule keeps verification cheap, but it means the screen layer needs its own reachability check — a story isn't done when the core is green if the player can't press the button. The 3.5 review caught it, but it should be caught by construction.
- **"Pin, not build" is the right shape for invariant ACs.** AC-1 (no combat XP) shipped as reflection + behavior pins with zero production code; AC-3 (knowledge survives) as a comparative seeded test. Invariant ACs don't need features — they need guardrails.
- **Deferral chains are the compounding engine (again).** 3.2→3.5 proved a deferred item can become a full story; the discipline turns out-of-scope into deliberately-timed scope.
- **AD-5-shifting vs AD-5-safe needs a standing classification** so triage decisions are consistent, not ad hoc — the most-repeated deferral reason across the epic.
