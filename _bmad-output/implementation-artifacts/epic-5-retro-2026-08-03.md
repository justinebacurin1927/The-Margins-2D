## What Went Well

- **The turn loop was suspended without touching `TurnEngine` — the cleanest possible FR-6.** 5.1 reused the existing modal-input gate (the same mechanism the inventory panel uses): the screen never calls `TurnEngine.advance` while a scene is open, so enemy/hunger/noise phases simply don't run. Zero pipeline edits, zero risk to the AD-4 invariants — and it directly heeded Epic 4's retro lesson ("a new acted-branch must honor the pipeline invariants") by *adding no new branch at all*.
- **The FR-6→FR-7→FR-8 chain closes end-to-end.** Passing the sample INSTINCT read → enters the success node → sets `scene.cache.revealed` → on scene close the cache spawns → survives save/reload without re-spawning. That is UJ-1 ("picks the INSTINCT option and uncovers a hidden cache with no fight") working in code, minus the authored prose (Epic 6). Each story's seam fed the next.
- **One content model, extended additively three times, never broke the legacy screen.** The reused `com.margins.dialog.DialogNode`/`DialogOption` gained INSTINCT fields (5.2) then flag fields (5.3) purely by addition; the legacy `com.margins.screen.GameScreen` kept compiling throughout (it reads only the original fields). The reviewer verified this explicitly.
- **The batched adversarial review earned its keep again.** It found one genuinely reachable bug the dev pass and harnesses missed — a cache revealed mid-scene is lost if the app is closed before the scene ends (the transient controller drops the open scene on reload). Fixed by consuming a pending reveal on load.
- **Empirical triage held — two loud "High" findings were disproven, not trusted.** "Cache spawns on an unwalkable tile" (the player's tile is *always* walkable) and "reward applied to a dead run" (the player can't die during a turn-suspended scene) were both dismissed by reading the call sites, not patched on the subagents' say-so. Severity was set from real reachability.

## Challenges & Recurring Debt

- **No committed test suite — now FOUR epics running (Epic 1 → 3 → 4 → 5).** Every 5.x story verified via a throwaway `main` harness (`DialogHarness` 15, `InstinctHarness` 12, `FlagHarness` 13 checks), deleted after the run. The dialogue state machine, the deterministic INSTINCT gate, and the flag persistence contract — all now core to the game — are guarded by nothing committed. This is the top open action item since Epic 1 and it is the single most overdue thing in the project.
- **Stacked-story signature churn left stale task text.** `DialogController.select` changed signature three times across the epic (`(int)` → `(int, instinct)` → `(int, RunState)`) as each story consumed the prior seam. It kept the design clean, but 5.1's task checkboxes still name the original `select(int)` — a harmless artifact the auditor flagged. When stories stack pre-review, earlier stories' literal text drifts from the shipped code.
- **The debug `T` trigger + `SampleDialog` ship in the build.** Spec-sanctioned scaffolding (it's what makes FR-6 exercisable), but it opens a placeholder scene and spawns a real persisted cache into the run economy. It must be removed/gated when Epic 6 authors the real opening.
- **Build/verify quirks still not centralized** (recurring Epic 1/3/4) — the `mvn -o -pl core install` + harness recipe is still re-stated per story.
