## What Went Well

- **The narrative seam was built ahead of its consumer, cleanly.** 4.3's `FlagStore` is exactly the AD-7 store that all of Epic 5 (branching dialogue, INSTINCT choices, scene/quest flags) will read and write through. The `applyBondTag` tag→delta authority means Epic 5 dialogue carries a stable tag constant and calls one method — no scattered `adjustBond` literals across content. Right altitude, no speculation.
- **Distraction reused the stealth stack with zero changes.** 4.2 emits a Noise event at Galleon's tile and lets the *existing* `NoiseSystem`/`DetectionSystem` resolve it (AD-9/AD-10). No detection code was touched; the companion still takes its follow step after the shout. A feature delivered almost entirely by composition.
- **The descent refactor preserved run state correctly.** 4.1 extracted `placeFloorActors` and reused the existing `RoguePlayer`/`Companion` objects via `placeAt` on descent, so HP/hunger/inventory carry across floors instead of being reset by a `new RoguePlayer(...)`. Verified by harness.
- **The batched adversarial code review earned its keep.** Reviewing all three stories at once (Blind Hunter + Edge Case Hunter + Acceptance Auditor, in a separate LLM per Justine's process) caught a **real gameplay bug the dev pass and the 4.1 harness both missed**: the descend turn ran hunger but skipped the Last Stand reprieve, so a starving player could permadeath on the stairs bypassing their one guaranteed reprieve.
- **Empirical triage discipline held (continuing the Epic 3 pattern).** Two subagent findings were disproven by reading the code rather than accepted: the "`roomCenters.get(0)` crash" (the first room is always added on a fixed 50×50 map → ≥1 room) and the "FlagStore `LinkedHashMap` round-trip is fragile" (the 4.3 harness already proved the round-trip). Severity was set from real reachability, not the worst theoretical reading.

## Challenges & Recurring Debt

- **No committed test suite — now recurring Epic 1 → Epic 3 → Epic 4 (third consecutive epic).** Every 4.x story verified via a throwaway `main` harness (`BondHarness`, `PatchVerify`, the 4.1/4.2 companion harnesses), deleted after the run. `FlagStore`'s Json round-trip is a *save-format contract* and nothing committed guards it. This has been the top open action item since Epic 1.
- **The Epic 3 `saveVersion` action item was mishandled — and reversed here.** Epic 3's retro decided "add `saveVersion` now" to close the save-migration gap. In Epic 4 a `saveVersion` field *appeared* in the diff — but as **dead code with no reader, writer, or migration logic** — and this epic's own code review **removed it** (Justine's call, option b). Net: the underlying save-migration gap is still open, and a dead field nearly shipped. **Lesson: an action item is "wire the mechanism," not "declare the field."**
- **A new turn-pipeline branch silently dropped a pipeline invariant.** `TurnEngine.advance`'s new descend branch ran `HungerSystem.tick` but omitted `CombatSystem.checkLastStand`, unlike every other acted turn. The happy path (descend + FOV) worked and passed the 4.1 harness; the invariant violation only surfaced under adversarial review. **Lesson: every new acted-branch in `TurnEngine` must be checked against the full-pipeline invariants (hunger → last-stand gate → FOV), not just its own happy path.**
- **Build/verify quirks still not centralized** (recurring Epic 1 item) — `mvn -o -pl core install` before `exec:java` and the `exec-maven-plugin:3.1.0:java` harness recipe are still re-stated per story.

## Next Epic Preview — Epic 5: Voices on the Road

Stories: **5.1** branching dialogue that suspends the turn loop · **5.2** INSTINCT-gated choices · **5.3** scene and quest flags.

- **Dependency on Epic 4 — met.** All three Epic 5 stories consume the `FlagStore` (AD-7) that 4.3 just built and verified. Scene/quest flags (5.3) use its generic `get/set/add`; INSTINCT-gated choices (5.2) pair with Bond reads; the `applyBondTag(null)` guard added in review means dialogue nodes can carry an *optional* Bond tag without crashing. The seam is ready.
- **Known risk — the legacy dialogue class is unwired.** `com.margins.dialog.DialogNode` is still a bare `text` + options with no `FlagStore` hookup. 5.1 must (a) connect dialogue read/writes to the `FlagStore` (AD-7: dialogue reads/writes narrative state *only* through the store), and (b) design the **turn-loop suspension** — dialogue is modal, so the AD-4 pipeline must pause while a conversation is open. That suspension is genuinely new control flow (the descend branch is the only recent precedent for a special turn path).
- **5.2 needs the INSTINCT threshold compare (AD-8).** The `instinct` stat already exists on the player (present in save data); 5.2 is a deterministic threshold gate, no RNG.
- **No significant discovery requiring an epic re-plan.** Epic 5's plan is sound and de-risked by the store being in place.

## Key Takeaways

1. Building the consumer's seam one epic early (the `FlagStore` for Epic 5) paid off — and reusing the stealth stack for Distraction shows the architecture's composition is holding.
2. The batched adversarial review is the safety net that's actually catching real bugs (the Last Stand permadeath), *because* it's run cold in a separate LLM and its findings are triaged empirically rather than trusted blindly.
3. Action-item accountability is the weak spot: 0/3 Epic 3 items landed, the test suite is three epics overdue, and a "done" action item (`saveVersion`) turned out to be dead code. Next epic, the test suite is the non-negotiable one.
