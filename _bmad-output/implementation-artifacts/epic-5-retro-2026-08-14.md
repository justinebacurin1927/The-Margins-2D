## What went well

1. **The "model now, content later" spine (the 5.1 pattern).** 5.1 established it (roster abstraction,
   one active tile-agent); 5.5/5.6/5.7 repeated it — ship the tested mechanical spine, defer the
   narrative payload. Every story stayed bounded, testable, and reviewable.
2. **Forward-designed seams paid off.** Story 2.5 built the `quest.<id>.*` flag family explicitly "for
   the act-gating stories, Epic 5," and 4.3 shipped a tested-but-inert per-act ramp. 5.6/5.7 collapsed
   to *wiring + tests* against those seams — a strong argument for planting seams at build time.
3. **The one-shot controller idiom compounded.** `CaptureController` → `ActGateController` →
   `BorderCrossingController`: the same "safe every-frame call on committed turns" shape, reused three
   times, each a stateless guard over persisted flags (AD-6). Cheap to add, easy to test.
4. **Inline review caught real bugs.** Two genuine defects that tests-as-written missed: a completed
   quest that never surfaced in the Journal (5.6, unstarted-quest rule), and dying-at-the-threshold
   counting as a win (5.7). Blind/Edge/Acceptance inline was sufficient — multi-agent not required.

## What was hard / where debt accrued

1. **The escalation ramps don't bite live.** `generateFloor` reads the act once at run start, so BOTH
   channel a (interior thickening, 4.3) and channel b (cordon thinning, 5.7) are only proven per-
   `(seed, act)` via regen — a single run never sees density change as the act flips. Epic 5 consumed
   the act flags but never wired the live world-reinforce. **Top carry-forward.**
2. **The content layer is thin.** 5.5 deferred personal/loyalty quests + withheld-help dialogue; 5.6
   deferred the prison-encounter that *decides* the rescue; 5.7 deferred the Act-3 provisioning spine
   and richer endings. "The Story" epic is mechanically whole but narratively sparse — a deliberate,
   coherent choice, but named here so it isn't forgotten.
3. **AD-5 determinism gotcha resurfaced.** 5.7's cordon placement shifted a byte-identical seed
   snapshot (`StructureContentTest`) until moved to the last rng consumer. Any new seeded draw shifts
   existing layouts — a recurring lesson worth codifying.
4. **Border-crossing balance is unproven.** The cordon can be empty in sparse-corner seeds (trivial
   win) and, per debt #1, doesn't thin live — so the "survivable only with Act-3 readiness" claim isn't
   yet real in play.

## Previous-retro follow-through

The 5 Epic-4 action items (screen-reachability gate; AG as a real 6th stat; deferred-work re-triage;
re-run a failed review layer once; CombatSystem invariants in 4.1) have sat **`open` through all of
Epic 5**. They are Epic-4-scoped, so Epic 5 did not naturally address them. Two epics of drift — they
need closing or re-verifying (see action item 2).

## Action items (Epic 5)

1. **Wire the live act-flip escalation (both channels).** Make crossing an act gate visibly change
   standing enemy density within a run — a regenerate-unexplored / reinforce-on-flip trigger so
   channel a thickens and channel b thins live, not only per-`(seed, act)` regen. Folds in the
   border-crossing balance concern (empty-cordon trivial wins). Owner: Dev.
2. **Close or re-verify the 5 stale Epic-4 action items.** Confirm which landed during Epic 4 and mark
   them `done`; re-scope any that are still real. No item should sit `open` two epics past its epic.
   Owner: Dev.
3. **Codify "append new seeded draws last."** Make the AD-5 rule explicit in create-story / dev
   guidance: new seeded placement goes after all existing draws so it never shifts prior seed layouts
   (the 5.7 cordon lesson). Owner: Dev.
4. **Author the deferred Epic 5 narrative content.** Give the systemic seams real payloads: 5.5's
   personal/loyalty quests + withheld-help dialogue, 5.6's prison-encounter rescue determinant, 5.7's
   Act-3 provisioning spine + richer endings / ending variants. Owner: Dev/design. (Does not block
   Epic 6.)

## Key takeaways

- Plant seams at build time — they turn later stories into wiring.
- "Model now, content later" is a proven way to keep a content-heavy epic bounded and testable — but
  track the content debt explicitly so the story layer eventually gets filled.
- New seeded draws go last (AD-5); inline Blind/Edge/Acceptance review keeps catching real bugs.
